# The objective is to completely remove the planner functionality from the contextual tool. This involves repurposing the prompt package to hold terminal utilities, stripping planner references from the main CLI logic and configuration, deleting the planner package altogether, and updating the project documentation to reflect these architectural changes.

The overarching goal is to strip out the `plan` subcommand, its associated logic, configuration, and package dependencies. The `contextual` tool will now focus solely on fetching context, as planning has been offloaded to a separate tool. Achieving this involves preserving interactive terminal prompts by moving them to the `internal/prompt` package, gutting planner-specific CLI logic from `main.go`, purging configuration structs and example files of planner settings, completely deleting the `internal/planner` directory, and updating the agent documentation to reflect the new system architecture.
